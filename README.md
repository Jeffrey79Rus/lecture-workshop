# lecture-workshop

강의, 교육 자료를 모아 두는 저장소입니다.

| 항목 | 내용 |
|---|---|
| 유형 | Lecture (강의, 워크숍 자료) |
| 공개 범위 | Public |
| 라이선스 | MIT |

## 폴더 구성

강의별로 폴더를 만들고 아래 구조를 기준으로 정리합니다.

```
lecture-workshop/
├─ README.md          저장소 소개 (이 파일)
├─ CLAUDE.md          Claude Code 작업 지침
├─ .gitignore         업로드 제외 목록
└─ YYMM-강의명/
   ├─ README.md       대상, 일시, 자료 목록
   ├─ slides/         발표 자료
   └─ handouts/       배포 자료
```

## 공개 자료 원칙

- 공개 가능한 자료만 올립니다. 내부 자료와 고객사 정보는 올리지 않습니다.
- 외부 자료는 출처를 표기합니다.
- 세부 규칙은 `CLAUDE.md`를 참고하세요.
