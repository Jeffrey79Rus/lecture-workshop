# lecture-workshop

강연·워크숍 자료 저장소 (GitHub Pages로 게시).

| 폴더 | 내용 | 주소 |
|---|---|---|
| `ax-latecomer/` | 후발주자 AX 강연 덱 | https://jeffrey79rus.github.io/lecture-workshop/ax-latecomer/ |

## 새 자료 추가
1. 자료별 폴더를 만들고 안에 `index.html`을 둔다. (예: `ax-session2/index.html`)
2. 루트 `index.html`의 목록에 카드 하나를 추가한다.
3. commit → push.

## 메모
- 모든 페이지에 `noindex`를 넣어 검색 노출을 줄였다. (완전한 비공개가 아님. 주소를 아는 사람은 열람 가능)
- 영상 등 대용량 파일은 올리지 않는다. 유튜브 링크 등으로 연결한다.
- `.nojekyll`: GitHub Pages가 파일을 임의로 가공하지 않게 하는 빈 파일.
